# Курсовая работа

EDA по плану из журнала работ:

- [Отзывы: 17 пунктов](notebooks/01_sentiment_eda.ipynb).
- [Сегментация животных: 25 пунктов](notebooks/02_pets_eda.ipynb).


## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Исходные данные уже находятся в `data/raw/`: три TXT в `sentiment/sentiment labelled sentences/`, изображения в `images/`, аннотации в `annotations/`. Архивы и их происхождение сохранены в `data/sources.json`.

Необходимые результаты сохраняются в `data/processed/`: разбиения отзывов, разбиения животных, кандидаты близких изображений и PNG-маски. Графики и статистика отображаются в ноутбуках.

Сегментация: 0 — фон, 1 — кошка, 2 — собака; 255 — игнорируемая неопределённость исходного Oxford. В собственной разметке закрашиваются только животные, фон получается из незакрашенной области.
