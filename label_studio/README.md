## Подготовка проектов

Запустить Docker Desktop, затем выполнить из папки `label_studio/`:

```sh
docker compose up -d
```

1. Открыть `http://127.0.0.1:8080`, создать учётную запись и проекты Sentiment и Pets.
2. В каждом проекте открыть Settings → Labeling Interface и вставить соответствующий XML.
3. Для Pets открыть Settings → Cloud Storage → Add Source Storage → Local Files. Указать `/label-studio/files/images`. Сохранить подключение **без Sync**, чтобы не создать дополнительные задачи из фотографий.
4. Импортировать в проекты соответствующие `*_tasks.json`.

JSON содержат сохранённые ответы и время разметки, а для фотографий – RLE-маски. Объекты сопоставляются по `object_id`, версия кодбука – 1.0.


## Исправленная партия и воспроизводимость

Экспорты `annotations/fixed/*-fixed.json` — предоставленная исправленная разметка, не автопредсказания. Суффиксы `-1` и `-2` соответствуют тем же С З и А М, что в таблице initial. Локальный `completed_by=1` не используется как глобальный идентификатор человека. Сопоставление объектов идёт по `object_id`; в `pets-1-fixed.json` недостающие ID добавлены из имён изображений и сверены с исходными заданиями. Все экспорты содержат версию кодбука 1.0. Числовые task ID между проектами не сопоставляются.

Если хотя бы один аннотатор сделал Skip (`was_cancelled=true`), объект остаётся исключённым. Сохранённый в отменённом ответе выбор не считается принятой меткой. Пропуски не заполняются за аннотаторов и не являются третьим классом тональности. Принятый пустой/некорректный ответ вызывает ошибку проверки, а не автоматически превращается в Skip.

## Расчёт Cohen, IoU и Dice

Из корня проекта после установки `requirements.txt`:

```bash
python label_studio/scripts/sentiment_metrics.py --stage initial
python label_studio/scripts/sentiment_metrics.py --stage fixed
python label_studio/scripts/pets_metrics.py --stage initial
python label_studio/scripts/pets_metrics.py --stage fixed --export-masks
```

Скрипты небольшие; общий `annotation_io.py` отвечает за проверку соответствия задач и декодирование RLE. Реализация формата сверена с [официальным конвертером HumanSignal](https://github.com/HumanSignal/label-studio-converter/blob/master/label_studio_converter/brush.py): все 206 brush-слоёв initial/fixed дали побайтово одинаковый RGBA. Для маски берётся alpha > 0; несколько областей одного класса объединяются. Перекрытие Cat/Dog внутри одной разметки, другая ориентация или несовпадение размеров вызывают ошибку.

Формулы:

- **Cohen’s κ = (p0 − pe) / (1 − pe)**: согласие меток с поправкой на ожидаемое случайное согласие. Считается только по объектам с принятыми метками обоих; skipped и их число публикуются отдельно.
- **IoU = |A ∩ B| / |A ∪ B|**.
- **Dice = 2|A ∩ B| / (|A| + |B|)**.

Для сегментации A/B — области одного класса двух аннотаторов в исходном разрешении. Если класс отсутствует у обоих, результат undefined и не входит в среднее; это не искусственная единица. Основная средняя IoU/Dice считается по присутствующим парам «фотография × класс животного»; фон показывается отдельно. Метрики симметричны, ни один аннотатор не объявлен ground truth. Это согласие людей, не точность модели.

| Партия | Принятых пар отзывов | Исключено по Skip | Cohen κ | Пар изображений | IoU животных | Dice животных |
|---|---:|---:|---:|---:|---:|---:|
| initial | 142 | 14 | 0.956996 | 51 | 0.908013 | 0.951433 |
| fixed | 142 | 14 | 1.000000 | 51 | 0.909636 | 0.952385 |

В initial совпали 139/142 принятых меток (97.89%), расхождения — sent_001, sent_004, sent_006. В fixed совпали 142/142: 61 Negative и 81 Positive. Всего каждый обработал 156 отзывов; второй пропустил 14. У обоих есть 51 принятая сегментация: 25 кошек и 26 собак. Улучшенное согласие fixed получено **после исправлений**, его нельзя выдавать за исходную независимую оценку.

Результаты скриптов — `annotations/metrics/{initial,fixed}/`: JSON со сводкой, CSV по каждому объекту и CSV IoU/Dice по каждому классу изображения. Пересчёт: одинаковая команда; пропуски остаются в аудите.

## Итоговые данные и обогащение

Выполнить [03_handmade_enrichment.ipynb](../notebooks/03_handmade_enrichment.ipynb) целиком. Первые два EDA-ноутбука приведены к версии main. Они формируют исходные CSV-разбиения, которые использует третий ноутбук.

- `data/processed/handmade/sentiment_all.csv`: все 156 объектов, обе метки, статус Skip/accepted/review_required, происхождение.
- `data/processed/handmade/sentiment.csv`: 142 принятых согласованных отзыва.
- `data/processed/handmade/pets.csv`: 51 фотография, источники, метаданные разметки, доли неопределённости и статус включения.
- `data/processed/handmade/masks/annotator_1/` и `annotator_2/`: обе декодированные разметки.
- `data/processed/handmade/masks/agreement/`: производная маска совпавших пикселей. Если аннотаторы расходятся, ставится **255 (ignore)**. Это область согласия, не экспертное разрешение каждой границы. По исходным разрешениям неопределённы 2.061% пикселей fixed.
- `data/processed/enriched/sentiment.csv` и `pets.csv`: объединённые манифесты исходных и новых данных с путями и `origin`, `group_id`, `split`. Строки `excluded_*` сохраняются для аудита и не используются в обучении.

Новые объекты добавляются только в train, исходные validation/test не пополняются новыми объектами. Проверяются нормализованные повторы текстов, SHA-256 файлов/RGB и pHash-кандидаты фотографий. Фотографии, совпавшие или близкие к Oxford, не включаются без проверки. Связанные новые фотографии имеют group_id источника и остаются в одной выборке. Это не доказательство отсутствия одного животного на разных снимках.

У Oxford семь полностью фоновых масок из trainval исключаются из итоговых train/validation до исправления. Официальный test (3669 объектов) сохраняется, включая семь дефектных масок; это ограничение итоговой оценки. Исходные CSV EDA и исходные изображения/маски не изменяются. Для обучения использовать ignore_index=255.

Фотографии собраны из публичных источников с авторами и лицензиями.
