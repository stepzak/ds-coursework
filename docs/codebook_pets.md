# Разметка кошек и собак

Версия 1.2

| Значение пикселя | Класс |
|---|---|
| 0 | Фон |
| 1 | Кошка |
| 2 | Собака |

## Правила

- Включать видимые голову, уши, тело, лапы, хвост и сплошную область шерсти.
- Скрытые части не дорисовывать. Если животное обрезано кадром, маска заканчивается на краю изображения.
- Просветы между лапами, предметы перед животным, поводок, тень и отражения относятся к фону.
- Отдельные усы и полупрозрачные волоски за основным силуэтом не обводить. Размытый край проводить по видимому основному силуэту при увеличении.
- Если вид или контур невозможно уверенно определить, пропустить фотографию и написать причину.

> В конце выгрузить полный JSON с RLE-маской и lead_time.

[Задания и инструкция Label Studio](../label_studio/).


## Единица разметки и порядок работы

Первоначальные ответы два аннотатора дают независимо, без просмотра ответов друг друга. Для сохранённой партии initial используется исходный экспорт, исправления хранятся отдельно в fixed. При обсуждении спорного случая применяется правило инструкции; исходный ответ не перезаписывается в архиве. Отмена задачи в Label Studio — Skip, не новый класс. Skip хотя бы одного участника исключает объект из итогового обучения; отсутствующие причины не придумываются задним числом.

Версия 1.2 уточняет обработку пропусков, сопоставление экспортов и производные обучающие данные. Наличие версии в каждом исходном JSON проверяется отдельно; отсутствующая версия не восстанавливается как факт.

Один объект — одна фотография независимо от числа штрихов или животных. Все видимые кошки/собаки размечаются соответствующим классом; несколько животных одного вида не получают отдельные семантические классы. Фон отдельно не закрашивается: незакрашенная область автоматически получает 0. Области одного класса объединяются, Cat/Dog не должны перекрываться на одном пикселе.

| Ситуация | Решение |
|---|---|
| Лапа частично закрыта сумкой | Разметить только видимую часть, сумку оставить фоном |
| Просвет между лапами | Оставить фон, не заливать вместе с телом |
| Тонкий поводок или тень | Фон |
| Животное уходит за край кадра | Маска заканчивается на краю; невидимую часть не дорисовывать |
| Две кошки в кадре | Обе видимые области имеют класс Cat |

## Экспорт и согласие масок

Сохраняются исходные RLE обоих аннотаторов и производные одноканальные PNG uint8 в исходном размере: 0 фон / 1 кошка / 2 собака. Граница не усредняется по числовым индексам классов. Метрики IoU/Dice рассчитываются между двумя самостоятельными масками, включая области их разногласий.

Для консервативного обучающего варианта формируется отдельная маска agreement: совпавшие пиксели сохраняют 0/1/2, несовпавшие получают 255 (ignore). Это служебное значение. Неопределённость исключается из loss и оценки такой целевой маски. Для будущей окончательной разметки спорную границу можно разобрать вручную; текущий вариант не выдаётся за такой разбор.
